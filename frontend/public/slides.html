Causa Raíz

La Confusión de Canales (CWE-89)

¿Por qué sigue existiendo SQLi tras 25 años en el OWASP Top 10?

CANAL DE DATOS (Entrada No Confiable del Usuario) ──┐ ├──> [ CADENA TEXTUAL CONCATENADA ] CANAL DE CONTROL (Comandos Sintácticos SQL) ─────────┘ │ ▼ ¡EL MOTOR MYSQL NO PUEDE DISTINGUIR DÓNDE TERMINA LA ORDEN Y DÓNDE EMPIEZA EL DATO!
❌ Concatenación Dinámica

Al concatenar strings, la entrada del usuario es parseada directamente por el compilador de la base de datos como una instrucción ejecutable.

✅ Separación Física por Protocolo

Las sentencias preparadas compilan la gramática antes de recibir el dato. El valor viaja en paquetes binarios independientes.

Gramática del Compilador

Anatomía de la Alteración del AST

Cómo el analizador sintáctico del motor relacional reestructura la consulta

[ CONSULTA ORIGINAL ] SELECT * FROM products WHERE id = [INPUT] AND is_active = TRUE; [ ENTRADA INYECTADA ] INPUT: 1 OR 1=1 [ CONSULTA FINAL ] SELECT * FROM products WHERE id = 1 OR 1=1 AND is_active = TRUE; ÁRBOL SINTÁCTICO (AST) REESTRUCTURADO: [ OR ] / \ (id = 1) [ TRUE ] [ AND ] / \ (1 = 1) [ TRUE ] (is_active = TRUE) RESULTADO: Como (1=1) es una tautología absoluta, el WHERE evalúa a TRUE para toda la tabla.
Defensa Perimetral

La Falacia de la Seguridad en el Borde (WAF)

Por qué la inspección perimetral de Capa 7 es insuficiente por sí sola

Atacante ──> [ HTTP: 1%2527%20OR%201=1 ] ──> [ WAF Capa 7 (Reglas Regex) ] │ ¿Bypass de Codificación? ───> │ (El WAF no ve palabras clave obvias) ▼ [ Servidor Web (Go/PHP) ] ── Decodifica el payload │ ▼ Syscall socket :3306 [ MySQL: Ejecuta la inyección ]
Evasión por Encodings

Double URL encoding (`%2527`), secuencias multicarácter UTF-8 y comentarios en línea (`UNI/**/ON`).

Ceguera de Contexto

El WAF desconoce el esquema interno de base de datos y cómo el driver interpretará los bytes.

Falsos Positivos

Reglas regex estrictas terminan bloqueando búsquedas de usuarios legítimos con comillas o tildes.

Contención Activa

Runtime Security con Cilium Tetragon

Interrupción en tiempo real de llamadas al sistema sospechosas

TracingPolicy en Kubernetes
apiVersion: cilium.io/v1alpha1 kind: TracingPolicy metadata: name: "block-sqli-runtime" spec: kprobes: - call: "sys_enter_write" syscall: true selectors: - matchArgs: - index: 1 operator: "Prefix" values: - "SELECT * FROM workshop_users" - "1 OR 1=1" matchActions: - action: Sigkill
Mecanismo de Interrupción

Cuando una consulta hacia el puerto 3306 coincide con un patrón anómalo no autorizado:

1. Hook en kprobe detecta el prefijo. 2. Tetragon genera evento de auditoría. 3. El Kernel despacha SIGKILL al hilo. 4. Conexión cerrada antes de procesar.

Vectores de Auditoría

Las 3 Sondas Simultáneas del Escáner

Cobertura integral de las principales variantes de explotación en CWE-89

1. Boolean Blind
Payload: 1 OR 1=1 Métrica: Diferencial DOM Efecto: WHERE evalúa TRUE. Muestra productos ocultos.
2. UNION Extraction
Payload: 0 UNION SELECT... Métrica: Fuga de registros Efecto: Concatena filas de la tabla workshop_users.
3. Time-Based Blind
Payload: 1 AND SLEEP(2) Métrica: Diferencial Latencia Base: ~15 ms Inyectado: > 1800 ms.

Remediación de Raíz

El Mecanismo de las Sentencias Preparadas

Por qué las Consultas Parametrizadas son 100% inmunes a la inyección

[ FASE 1: PREPARE (Compilación del AST) ] El cliente envía la plantilla vacía: "SELECT id, name, price FROM products WHERE id = ? AND is_active = TRUE;" └──> El motor MySQL compila el AST. El signo '?' es fijado como un valor escalar literal. [ FASE 2: EXECUTE (Paso de Datos por Protocolo Binario) ] El cliente envía el parámetro: Parámetro: "1 OR 1=1" (Tipo: String) └──> MySQL busca productos cuyo id sea textualmente la cadena "1 OR 1=1". └──> ¡IMPOSIBLE QUE EL DATO ALTERE LA LÓGICA DE LA CONSULTA PRECOMPILADA!

TICEC 2026 · CONCLUSIONES

Conclusiones y Discusión Abierta

1. Diseño, no Parches

CWE-89 se soluciona separando el canal de datos del canal de control mediante sentencias preparadas.

2. El Kernel no Miente

eBPF elimina la ceguera de los WAFs de Capa 7, ofreciendo observabilidad y contención en Capa 0.

3. Sinergia Purple Team

La combinación de ataque automático con entrega de parches inmediatos reduce el tiempo de remediación a minutos.
